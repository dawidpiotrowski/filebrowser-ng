## Important remaining boundaries

- **Rename still has a no-replace race.** An existence check followed by ordinary rename is not an atomic no-overwrite operation. NG-14 closes the file-copy branch; it does not close rename, make recursive copies transactional, or isolate staging files.
- **Overwrite is not crash-safe.** Existing uploads, editor writes and explicit copy overwrites can damage the previous destination after truncation if a write fails. Sync/Close success does not establish parent-directory durability or coordinate external writers.
- **TUS identity is narrower than a full write lease.** It detects a different filesystem object, not modifications to the same inode or all host-side races. DELETE still has a stat/remove interval and retains its Delete permission requirement. State remains in memory with the existing expiry/restart behavior. Opaque upload IDs, persistent leases, inode reuse, aliases/case normalization, and coordination with every mutation need a broader design.
- **Browser JWTs remain JavaScript-readable in localStorage.** This pass fixes same-tab lifecycle races. It does not implement HttpOnly browser sessions, CSRF protection for a cookie-authenticated write API, or multi-tab renewal coordination. A stale renewal response skipped after another login can leave its unused server session until expiry.
- **Shares still permit permanent, passwordless links.** Longer identifiers and arithmetic validation do not add maximum/default lifetimes, password policy or a grant-management UI. Administrators still need a future inventory/revocation policy for old short IDs.
- **File-adapter capabilities need an explicit contract.** Review nested filesystem adapters before extending them: a returned OS file handle alone does not establish that bypassing the adapter preserves its restrictions. Directory copies also need resolved parent/alias checks and bounded traversal; lexical path comparisons alone are insufficient. These are follow-up design/review items, not a new demonstrated anonymous exploit.
- Effective script CSP, content-origin isolation, quotas and running-decoder limits remain open. No new anonymous authentication bypass was confirmed here. Windows compilation is useful but does not establish behavior on real Windows volumes or NAS filesystems.
