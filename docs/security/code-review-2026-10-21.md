# Code review: filebrowser-ng, 2026-10-21

This second review starts at `b62da31b36447892e32f2b0a77db6dcc22cc550b` (`v2.64.0-ng.2`). It examines request validation and authorization, user storage, file copy/move error paths, search, previews/cache, rules, browser bootstrap, and HTTP routing. It complements the [upstream advisory review](audit-2026-10-21.md); it is not an exhaustive certification or a replacement for deployment testing.

All findings below are fixed in the source prepared for **2.64.0-ng.3**. Severity is a maintenance assessment, not a CVSS score. In particular, the credential issue requires an existing administrator session; it is not an anonymous login bypass. Tests use disposable local data, not the public NAS instance.

## Findings

| ID | Priority / impact | Trigger and previous behavior | Fix and regression evidence |
| --- | --- | --- | --- |
| NG-01 | High: persistent account takeover after administrator-session theft | `PUT /api/users/{id}` with missing, null, or empty `which` performs a complete replacement but skips current-password verification. `lockPassword` also misses verification because its mixed-case map key is compared with lowercase input; `rules` is missing from the sensitive set. | Canonical, explicit field policy; all complete replacements and sensitive changes require the current password under JSON auth. `TestUserSensitiveUpdatesRequireCurrentPassword` reproduced HTTP 200 before the fix, now 400 with unchanged credentials. Ordinary preferences still work without reauthentication. |
| NG-02 | Medium: partially applied failed requests | A normal user submits `which: ["locale", "doesNotExist"]`: locale is saved before the request fails with HTTP 500. Runtime `Fs` and identity `ID` can also reach the storage reflection layer. Complete replacements skip the share-implies-download consistency check. | Validate the entire editable-field list before writing; reject `ID`, `Fs`, unknown fields and mixed `all` requests; enforce permission consistency for full replacements. Multi-field Bolt updates use one transaction. `TestUserUpdatesValidateEveryFieldBeforeWriting`, `TestUserFullUpdateEnforcesShareDownloadInvariant`, `TestUserFieldUpdateRollsBackWhenLaterFieldFails`. |
| NG-03 | Low: authenticated request panic | A user-modification body with `what: "user"` but no `data` passes decoding and dereferences a nil pointer. Go's HTTP server recovers that request; this is not a whole-process crash. | Reject missing/null data as HTTP 400 in the shared create/update decoder. `TestUserUpdateRejectsMissingData`. |
| NG-04 | High: loss of a pre-existing destination file | Any failed rename falls back to copy/delete. If reading the source then fails, the fallback unconditionally removes the destination, including a file that predated the operation. A failed permission check can also be bypassed by a successful copy/delete fallback. | Copy fallback is restricted to actual cross-device errors, including Windows' equivalent. Failed copies retain the source and no longer delete the destination. `TestFailedMovePreservesExistingDestination` reproduced a missing destination; `TestMoveDoesNotFallbackOnPermissionFailure` reproduced unexpected success; normal cross-device movement remains covered. This does not make overwrite/copy fully atomic on disk-full or mid-write failure. |
| NG-05 | Medium: administrator lockout | Two simultaneous administrator deletions can both see another administrator and both succeed. Updating or fully replacing the last administrator can also remove the final admin role. | Serialize user writes with last-admin checks; guard demotion through `Update` and `Save`, shared by HTTP and CLI. `TestAdminDeletionAndDemotionKeepOneAdministrator` reproduced removal of both admins before the fix; exactly one removal now succeeds and the survivor cannot be demoted. |
| NG-06 | Medium: persistent broken access policy | Settings accept a regex rule with missing `regexp` or invalid syntax such as `[`. The first matching file request panics. A malformed persisted policy has no safe failure behavior. | Validate global/user rules before persistence; replace `MustCompile` with checked compilation; synchronize the compiled-expression cache. Existing invalid rules deny file access while the settings UI remains available for repair. `TestSettingsRejectInvalidRegexRulesWithoutPersisting`, `TestExistingInvalidRulesDenyAccessWithoutPanic`. CLI syntax errors return normally. |
| NG-07 | Medium: missing framing/navigation protection | Router middleware runs on matching API/static routes but not `NotFoundHandler`, which serves `/`, `/login`, `/files/` and settings. Those application pages have no CSP. | Security headers wrap the entire router, including fallback pages and redirects. Add `frame-ancestors 'self'`, `base-uri 'self'`, `form-action 'self'`, `SAMEORIGIN`, `nosniff`, no-referrer and camera/microphone/geolocation restrictions. Preserve same-origin PDF embedding and the stricter API/user-content policy. `TestSecurityHeadersCoverApplicationFallbackAndAPI` covers eight routes. **The application HTML still lacks a script-restricting CSP; nonce support is planned.** |
| NG-08 | Low: interrupted or misleading search results | A file disappears between directory listing and stat; search ignores the error and passes nil metadata to the HTTP callback. A missing root silently succeeds. The one-shot heartbeat timer sends only one heartbeat during a long search. | Skip disappeared/unreadable children, report root/other I/O errors, release the derived context, and use a recurring heartbeat ticker. `TestSearchDoesNotPassMissingMetadataToCallback`, `TestSearchReturnsRootError`. |
| NG-09 | Low: stale thumbnails | Cache keys use only whole-second modification time and omit file size. Two replacements in one second use the same entry. | Include nanosecond modification time, size, and explicit key boundaries/version. `TestPreviewCacheDistinguishesChangesWithinOneSecond`. Preserved identical size/timestamps can still conceal an external content change; this is not content-addressed storage. |
| NG-10 | Medium: cache corruption symptoms and memory growth | Cache reads are not locked against writes: a cache hit can read zero bytes after truncation but before the new image is written. A permanent lock map grows with every distinct cache key, including deletes. | Readers and writers share fixed, bounded RW-lock stripes. `TestCacheReadersNeverObserveAnInProgressWrite` reproduced a successful empty cache read. Disk cache size and failed-write atomicity still need separate controls. |
| NG-11 | Low: abandoned preview work | Thumbnail generation replaces the request context with `context.Background()`, so disconnected clients remain queued for image-worker slots. | Pass request cancellation to `Resize` and its semaphore acquisition. `TestPreviewPropagatesRequestCancellation`. This does not interrupt a decoder already running CPU work. |
| NG-12 | Medium: process termination on database error | A request-time settings read failure calls `log.Fatalf`, exiting the entire server. | Log the failure and return HTTP 500 without invoking the handler. `TestSettingsReadFailureReturns500`. The pre-fix termination is identified directly in code; the final regression verifies the corrected behavior. |
| NG-13 | Low: fork maintenance error | The error toast and issue-template links send users to the archived upstream project. | Send reports, version references and support links to this fork. These reversible URL corrections do not need implementation-mirroring tests. |

The targeted regressions were run before repairs wherever practical: credential bypasses, partial updates, invalid permissions, lost move destinations, permission-error fallback, search errors, malformed rules, missing headers, preview identity/cancellation, the cache read/write race and simultaneous admin deletion failed as described. Existing successful operations remain covered alongside the new rejection paths.

## Review boundaries and next work

- The earlier protections for scope confinement, revocable sessions, public-share permissions, bounded text reads, archive traversal and TUS offsets are retained and exercised by the complete regression suite. No new anonymous authentication bypass was confirmed in this pass.
- Browser JWTs remain in localStorage, and renewal is coordinated only within a tab. Moving browsers to HttpOnly sessions requires a deliberate CSRF and multi-tab design, not merely deleting the localStorage assignment.
- Copy, rename and overwrite still need a common atomic commit/no-replace policy across platforms. Existing destination checks precede later I/O. Interrupted overwrites can truncate an old file; this pass removes the additional unconditional delete but does not claim crash-safe writes or complete concurrency fencing.
- User content is still served from the application origin. Raw files retain `script-src 'none'`; a separate content origin or sandbox design needs media/PDF/EPUB compatibility tests.
- Large directory listings, archive construction, disk cache, image decoding and concurrent downloads need configurable resource budgets. Thumbnail worker cancellation now reaches the queue; running decoders need a different isolation/limit design.
- These tests do not exercise host administrators, external writers, NAS filesystem quotas, proxy configuration, real Windows cross-volume I/O, or every browser/media workflow. Keep the documented single-writer and least-privilege deployment boundaries.

The [security roadmap](roadmap.md) turns these boundaries into ordered features with acceptance criteria. [Migration notes](../migration.md#changes-in-2640-ng3) describe behavior changes.

## Validation

Local macOS arm64 verification: `go vet ./...`, complete `go test -race -timeout 5m ./...` (**263 passing tests/subtests**), frontend lint, **35 passing tests**, typecheck and production build. The concurrent last-administrator regression also passes 25 successive runs. `govulncheck@v1.9.0` reports zero reachable vulnerabilities and zero vulnerable imported packages, with the previously documented unused module advisory. The pnpm audit gate passes with the one existing, narrowly scoped advisory exception backed by the braces patch and tests. No dependency exceptions were added.

Release CI additionally runs Linux race tests and native Linux amd64/arm64 container smoke tests before publication. The default branch runs Windows/macOS checks as well. Publication status and immutable image identity are recorded in the GitHub release, not inferred from a local build.
